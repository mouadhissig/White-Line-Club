# White Line Club ISSIG

A modern, animated website for the White Line Club at L'Institut Supérieur de Sciences Infirmières Gabès.

## Features

- 🎨 **Modern Black & White Theme** - Clean, professional design with a striking monochromatic color scheme
- ✨ **Smooth Animations** - Scroll-triggered animations and interactive elements
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🚀 **Fast & Lightweight** - Pure HTML, CSS, and JavaScript with no heavy dependencies

## Sections

1. **Hero Section** - Eye-catching introduction with animated geometric shapes
2. **Who We Are** - About the club with animated statistics
3. **Our Achievements** - Showcase of accomplishments with card animations
4. **Our Goals** - Vision and objectives with modern list design
5. **Sponsors** - Partner showcase with placeholder for sponsor logos
6. **Contact Us** - Contact form and information with social media links

## Getting Started

Simply open `index.html` in a web browser to view the website.

### Development

The project structure:
```
White-Line-Club/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # Stylesheet with animations
├── js/
│   └── main.js         # JavaScript for interactivity
└── README.md           # This file
```

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Poppins)

## Customization

- **Colors**: Edit CSS variables in `:root` selector in `style.css`
- **Content**: Update text content directly in `index.html`
- **Sponsors**: Add sponsor logos to the sponsors section
- **Contact**: Update contact information and social media links
